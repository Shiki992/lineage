Lineage

Help

Lineage keeps one master of your resume, deck or workbook in step with the versions you tailor from it, and records every copy you send.

Getting started

  1. In Word, PowerPoint or Excel, go to Home › Add-ins, search for Lineage and add it.
  2. Open your file, then Lineage on the Home tab.
  3. Sign in with your Microsoft account, then choose Start tracking.

Everything Lineage keeps is in your OneDrive, in Apps › Lineage: your tailored versions, the copies you've sent, and their history. My documents shows all of it.

Common questions

The panel says "Shared with you" or "History not found"

The file is tracked in someone else's OneDrive, usually the person who shared it with you. Edit it as usual; they'll see your changes in their Lineage. If you tracked it yourself, sign in with the account you used then.

A version says "Not updated: it's open"

Someone has that file open, maybe you in another window, or someone you shared it with. Update it again once it's closed.

In Excel on the web, why "the last saved version"?

Excel on the web doesn't let add-ins read the open workbook, so Lineage reads the copy in OneDrive. Excel saves as you go, so it's usually only seconds behind.

Does Lineage run macros?

Never. It reads macro and query code as text to show what changed. Code that comes back from someone else is always shown on its own, for you to decide.

Report a problem

  • Open an issue on GitHub. If Lineage showed "Lineage stopped working", choose Copy details there and paste them in.
  • Please don't attach real documents with anyone's personal details.
  • Report security problems privately, as the security policy describes.
