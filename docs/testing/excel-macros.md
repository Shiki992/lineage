# Manual test: macros, pivot tables and Power Query

The Phase 5B "done when" check, run by hand in Excel for Windows: the founder's financial model with macros, two pivot tables on one cache and two Power Query queries shows each kind of change; a copy that comes back with new macro code shows the warning; and nothing needs macros turned on. About 20 minutes.

Lineage never runs, compiles or evaluates macros or queries. **Leave macros disabled the whole time**: if Excel shows "Macros have been disabled" with an **Enable Content** button, don't press it. Don't refresh the queries either (Data › Refresh All, or editing a query in the Power Query editor, evaluates its M code; Lineage doesn't need it).

Use invented workbooks only. `cargo xtask fixtures` writes them to `fixtures/xlsx/synthetic/`:

- `model-full-for-excel.xlsm`: the model with macros (ThisWorkbook and Sheet1 code, the module Forecast with `RefreshForecast`, the class Scenario), a Sales sheet, two pivot tables on a Pivots sheet (RevenueByRegion with a Month filter, SeatsByPlan) with a Region slicer on both, and two queries (Rates, loaded to its own sheet, and RegionList, connection only).
- `model-full-returned-for-excel.xlsm`: what an investor sends back, without Lineage's ids: a new module Mailer, `RefreshForecast` calling it, the Rates query edited, and a seat count corrected on Sales.

Copy both into a scratch folder first; rename the first "Startup model.xlsm".

**The master's macro edit (steps 3, 8 and 10, and the macro parts of 6 and 15) needs a VBA project Excel made itself.** Excel keeps the invented project's code while nobody edits it, but after an edit it can't save the workbook ("Errors were detected while saving …"; cancel that). That is the VBA spike's finding (decision 0028). For those steps, make "Macro model.xlsm" in Excel: a new workbook, **Developer › Visual Basic**, **Insert › Module**, name it Forecast in Properties, paste the Forecast code from the model (Copy code on any macro card gives it), and **Save As** Excel Macro-Enabled Workbook in the scratch folder. Then run steps 1, 3, 6 to 10 and 14 to 15 on it.

Setup is as in [excel-pilots.md](excel-pilots.md) (certificate, sideload, `LINEAGE_DEV_STORAGE`, the pane's server). The pane needs ExcelApi 1.7; Excel for the web isn't supported yet (decision 0020).
