# @lineage/shell

The typed TypeScript wrapper around the Lineage wasm engine. From Phase 2 it also holds the storage interface the OneDrive and Drive adapters implement.

- `loadEngine(wasmBytes)` initialises the engine and returns a typed `Engine`.
- Every value that comes back across the boundary is checked; a bad one throws `EngineBoundaryError`.
- TypeScript never parses document XML. Bytes go in, bytes come out.

`wasm-pkg/` is generated by `scripts/build-wasm.mjs` and is not committed. `pnpm test` and `pnpm typecheck` build it first.

```bash
pnpm --filter @lineage/shell test
```

Tests:

- `bridge.test.ts`: the engine reports the Rust workspace version, and byte buffers (empty, 1 byte, 256 bytes, 1 MB) round-trip unchanged.
- `spec.test.ts`: the `spec/format/v0` examples checked with ajv (draft 2020-12), mirroring the Rust tests.
