# .docx fixtures

Test documents for the Word engine. Every file here must be one we may redistribute under the project's licence. **Never add real documents or real people's data.** Example resumes and decks are invented.

The maintainer's own documents live in the git-ignored `test/` folder at the repository root, for local fidelity runs only. Never copy them here, and never quote their content in commits, issues or logs.

## Synthetic fixtures (`synthetic/`)

Generated by `cargo xtask fixtures` from `crates/testkit/src/fixtures.rs`. The output is deterministic: entries are stored uncompressed in a fixed order with fixed timestamps. CI runs `cargo xtask check-fixtures` to make sure the committed files match the generator exactly.

## Adding a fixture

1. **Synthetic** (preferred): add a function to `crates/testkit/src/fixtures.rs`, list it in `all()`, run `cargo xtask fixtures`, and add a row to the table above.
2. **Hand-made** (for quirks only a real app produces, such as Word's own revision IDs or a Google Docs export):
   - Create it with invented content only.
   - Save it under `fixtures/docx/<app>/`, for example `word/` or `google-docs/`.
   - Add a row giving the app and version that saved it, who made it, and the licence (Apache-2.0 for contributors, under the DCO).
3. **Bugs:** every engine bug gets a fixture that reproduces it and a test that uses it.
4. If LibreOffice is installed, check the new file opens headless. On Windows with Word, `scripts/word-smoke.ps1 <folder>` does the same.
