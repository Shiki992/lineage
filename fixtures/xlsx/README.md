# .xlsx fixtures

Test workbooks for the Excel engine. Every file here must be one we may redistribute under the project's licence. **Never add real workbooks or real people's data.** Brightwell Analytics, Harbor Lane Capital, Northwind Angels, every company in the job tracker, every shop in the budget and every figure are invented.

## Synthetic fixtures (`synthetic/`)

Generated by `cargo xtask fixtures` from `crates/testkit/src/xlsx.rs` (the builder) and `crates/testkit/src/workbooks.rs` (the workbooks). The builder never uses the engine. Output is deterministic: entries are written in a fixed order with fixed timestamps, deflated unless the table says otherwise. CI runs `cargo xtask check-fixtures` to make sure the committed files match the generator exactly. Cached results are computed with exact decimal arithmetic, so they agree with the formulas.

Every workbook has a styles part with nine cell formats (General, `0%`, `#,##0`, `yyyy-mm-dd`, bold, `"$"#,##0`, text, `0.00%`, `#,##0.00`), a shared-strings table, and core and app properties.

### Macros, pivot tables and Power Query (Phase 5B)

Built by `crates/testkit/src/advanced.rs` with `vba.rs` (a compound-file writer, the VBA compression and projects in the spec's on-write form), `pivots.rs` (pivot caches, pivot tables with their output cells, slicers) and `mashup.rs` (Power Query's DataMashup item). The macros are invented and harmless (a status-bar message, a few cell writes); Lineage never runs them. The form `ScenarioForm` has a stand-in designer, not a real form, and the signature is a stand-in PKCS#7 for the invented signer "Fabrikam Test Signing", so files with either are for the engine's tests only. The `-for-excel` and `-only` files are the ones opened in real Excel.

## Saved by real Excel (`excel/`)

Made by `scripts/excel-resave.ps1` from the synthetic workbooks above, in its own Excel instance (Microsoft 365, Current Channel, Windows). Excel recalculates every workbook before saving. After saving, the script takes out what Excel stamps into every file about who saved it and where: the last author (set to "Lineage fixture generator"), the folder path (`x15ac:absPath`) and this computer's sensitivity label (`docMetadata/LabelInfo.xml`). The sheets are as Excel wrote them.

What these showed (recorded in decisions 0020 and 0022):

- Excel writes numbers with up to 17 significant digits: a typed 151.3 is saved as `151.30000000000001`. Numbers are compared by the double they stand for, never by their text.
- Excel's recalculation can leave a calculated result a unit in the last place away from exact decimal arithmetic. Calculated results are compared at the 15 significant digits Excel shows.
- `TODAY()` moves on by itself when Excel recalculates.

`scripts/excel-smoke.ps1 <folder>` opens workbooks in real Excel and reports any it had to repair; every file here (except `model.xlsm`) opens cleanly, and LibreOffice opens them headless.
